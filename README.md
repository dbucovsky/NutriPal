# NutriPal

A web app for accessing and analyzing personal health data from Google Health (formerly Fitbit), viewed from the desktop — with deeper macro/micronutrient analysis, activity analysis (running, workouts, etc.), and correlation between activity, food, and weight over time.

Currently in planning/rebuild — no application code exists yet.
