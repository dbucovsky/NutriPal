# NutriPal

A web app for accessing and analyzing personal health data from Google Health (formerly Fitbit), viewed from the desktop — with deeper macro/micronutrient analysis, activity analysis (running, workouts, etc.), correlation between activity, food, and weight over time, and fast custom/repeat meal logging.

The database schema, data ingestion (Health Connect bulk import), and live Google Health API sync are built and running against real data. No application/UI exists yet — that's the current focus.
